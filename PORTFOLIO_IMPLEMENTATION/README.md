# Portfolio Implementation Workspace

This folder is a clean local implementation workspace for Shani Nakash-Gomel's portfolio website and integrated Role Fit Agent MVP.

It is not the active production website root and does not replace the existing Git/Vercel-connected project setup.

## Structure

- `website/current-site-materials`  
  Reference copy of the current portfolio website materials.

- `role-fit-agent/IMPLEMENTATION_PACKAGE`  
  Local copy of the approved Role Fit Agent implementation package.

- `role-fit-agent/docs/canonical`  
  Canonical Markdown copies from the implementation package, preserved without renaming or content edits.

- `assets`  
  Reserved for portfolio visual assets, exports, images, and related media.

- `design-system`  
  Reserved for design-system materials, tokens, component guidance, typography, and visual language documentation.

## Current Scope

This workspace was created for organization only.

No application logic, model calls, runtime behavior, report generation, or repository foundation work has been implemented in this step.
