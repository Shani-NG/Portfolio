## Evidence Cards

E-ROLE-FIT-01 — Evidence-based AI product
Claim: Shani designed, built and operationalized an evidence-based AI portfolio experience that turns static work into a transparent professional conversation.
Best public anchor: overview.

E-ROLE-FIT-02 — Deterministic orchestration
Claim: A single conversational experience is supported by governed task modes, structured evidence retrieval, runtime controls and persistent system services; the model interprets and synthesizes while the application remains authoritative.
Best public anchor: technical-architecture.
Capabilities: agentic workflows, agent orchestration, RAG planning, validation and eligibility logic, report data model.
Limit: Documents product and application architecture, not foundation-model development or ML research.

E-ROLE-FIT-03 — Validated report flow
Claim: The system validates the input, presents a concise role snapshot for confirmation, analyzes the role against verified portfolio evidence, and generates a qualitative report that distinguishes strengths, transferable capabilities, unknowns and genuine gaps.
Best public anchor: product-story.
Capabilities: role validation, role-fit report generation, evidence-based AI reasoning, conversation design.
Limit: Does not prove automated hiring decisions or a quantitative prediction of job performance.

E-ROLE-FIT-04 — QA and privacy-aware persistence
Claim: Shani designed QA scenarios for invalid inputs, injection, timeouts, weak evidence and session limits, and defined logging, privacy-aware persistence and a human-reviewed learning loop without storing raw job-description text.
Best public anchor: decision-evolution.
Capabilities: QA and edge-case handling, logging and monitoring, privacy-aware persistence, human-reviewed AI workflows.
Limit: Documents the product architecture and MVP decisions; it does not claim enterprise-scale governance or deployment.
