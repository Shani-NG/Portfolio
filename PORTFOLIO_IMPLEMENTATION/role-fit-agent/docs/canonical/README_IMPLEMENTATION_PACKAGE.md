# Role Fit Agent — Implementation Package

This folder is the implementation-ready documentation package for building the Role Fit Agent repository.

## Usage

1. Download this entire folder from Google Drive.
2. Place the files under the repository documentation area, preferably `/docs/canonical/`.
3. Treat these filenames as stable canonical names.
4. Do not rename active canonical files without updating all references.
5. Before replacing an approved file, archive the previous copy using a versioned filename.
6. The Google Drive documents outside this folder remain the readable master and backup set.
